# Security And Privacy

These documents describe current security and privacy design, trust boundaries,
data handling, and accepted controls.

- [`threat-models/`](threat-models/) contains scoped threat models.
- [`data-handling.md`](data-handling.md) defines project data classes and
  lifecycle expectations.

Security audits belong in [`audits/`](../audits/). Security incidents belong in
[`operations/incidents/`](../operations/incidents/). Vulnerability reporting
instructions commonly belong in a repository-root `SECURITY.md`; link that file
here when present.
