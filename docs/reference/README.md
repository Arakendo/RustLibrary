# Reference

Reference documents provide stable, factual descriptions of the system: its
configuration, commands, formats, compatibility, vocabulary, and public
contracts.

Reference material answers “what is available?” Guides answer “how do I
complete a task?” Avoid duplicating generated API documentation; link to its
canonical output and document only project-level interpretation here.

Copy `TEMPLATE.md` for a new reference page. Maintain shared terminology in
[`glossary.md`](glossary.md).
