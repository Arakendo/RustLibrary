# Implementation Plans

Plans describe concrete implementation work: scope, ownership, incremental
slices, validation, risks, and completion criteria.

Plans are not architectural decisions. If implementation evidence challenges
an established boundary, open an Architectural Review and update or supersede
the relevant ADR deliberately.
