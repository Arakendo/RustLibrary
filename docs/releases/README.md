# Releases

Release documents coordinate a supported version or delivery event. They
connect accepted requirements, implementation evidence, compatibility changes,
migrations, operational readiness, and communication.

Copy `TEMPLATE.md` to a filename containing the version or release name.
Long-lived release notes may instead live in a conventional repository
`CHANGELOG.md`; link that canonical record from here rather than duplicating it.
