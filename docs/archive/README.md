# Archived Documentation

This directory contains superseded or intentionally retained historical
material. Archived documents may explain how the project arrived at its current
architecture, but they are not current policy.

When archiving a document:

1. add a banner that names the archive date and replacement, if any;
2. update links from current indexes;
3. link the replacement back to the archived document when history is useful;
4. do not continue editing the archived document as current truth.

If an archived idea becomes active again, create or update a current Note, Plan,
Architectural Review, or ADR rather than editing history into present tense.
