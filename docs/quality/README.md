# Quality Attributes

Quality documents define cross-cutting expectations that shape design and
acceptance: accessibility, performance, reliability, maintainability,
portability, localization, and similar concerns.

Use `TEMPLATE.md` for each quality attribute the project actively maintains.
State measurable expectations and validation methods; avoid aspirational prose
that cannot guide design or acceptance.

Testing mechanics belong in [`testing-strategy.md`](../testing-strategy.md).
Point-in-time measurements and conformance findings belong in
[`audits/`](../audits/).
