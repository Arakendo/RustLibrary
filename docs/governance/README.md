# Project Governance

Governance documents define ownership, decision rights, review expectations,
and documentation maintenance. They describe how the project is stewarded,
not its software architecture.

- [`ownership.md`](ownership.md) identifies durable responsibility.
- [`decision-process.md`](decision-process.md) explains how proposals become
  accepted policy.
- [`documentation-policy.md`](documentation-policy.md) defines documentation
  ownership and health expectations.

Repository-level contribution rules, codes of conduct, and security reporting
instructions may need conventional root filenames. Link them from this index
rather than maintaining competing copies.
