# Subsystem Designs

Subsystem design documents describe the current intended architecture and
contracts of a bounded part of the system. They refine
[`design-document.md`](../design-document.md) without overriding project-wide
constraints or accepted ADRs.

Create a subsystem design when a component has enough ownership, interfaces,
state, failure behavior, or security constraints to make a dedicated current
reference useful. Do not create one merely to restate code structure.

Copy `TEMPLATE.md` to a descriptive lowercase filename and add it to the index.
