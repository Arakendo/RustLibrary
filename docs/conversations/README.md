# Source Conversations

This directory preserves discussions, interviews, workshop notes, and research
inputs that informed the project.

Conversation records are evidence and context, not authoritative contracts.
Extract durable conclusions into a Note, Plan, Architectural Review, ADR, or
current design document so readers do not need to search conversational history
to discover the project's rules.

Use descriptive filenames and record the date, participants or source, context,
and links to any durable conclusions derived from the conversation.

Copy `TEMPLATE.md` when a lightweight, consistent capture format is useful.
