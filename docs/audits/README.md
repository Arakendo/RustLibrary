# Audits And Assessments

Audits record observed implementation conformance, defects, risks, and
recommendations at a point in time. Common scopes include architecture,
security, privacy, accessibility, performance, reliability, and documentation.

An audit is evidence, not architecture. It may trigger a plan, Architectural
Review, ADR, incident follow-up, or design update, but it does not silently
override those documents.

Copy `TEMPLATE.md` to `YYYY-MM-DD-short-scope.md`. Preserve completed audits as
historical evidence; create a new audit for a later assessment rather than
rewriting the earlier observation.
