# Product Requirements

Requirements state accepted, testable behavior or constraints. Each requirement
should identify its user or stakeholder value, priority, evidence, acceptance
criteria, and owner.

Copy `TEMPLATE.md` to `REQ-NNNN-short-title.md` and add it to the index. Use
stable identifiers when requirements are referenced by tests, plans, releases,
or compliance evidence.

Implementation details belong in design documents and plans. Unvalidated ideas
belong in notes or research records.
