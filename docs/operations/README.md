# Operations

This optional category is for projects that run deployed systems or maintain
stateful production environments. Libraries and offline tools may delete it.

Operational documents describe how to observe, operate, recover, and safely
change a running system. Keep environment-specific secrets out of documentation.

- [`runbooks/`](runbooks/) contains repeatable operational procedures.
- [`incidents/`](incidents/) contains incident learning records.

Add service objectives, monitoring strategy, backup and restore policy,
disaster recovery, and release procedures here when the project needs them.
