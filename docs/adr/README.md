# Architecture Decision Records

ADRs record accepted architectural decisions and their consequences. They are
binding until explicitly superseded.

Copy `TEMPLATE.md` to `ADR-NNNN-short-title.md`, assign the next unused number,
and add it to the index. Never reuse a retired number.

## Statuses

- **Proposed**: awaiting a decision.
- **Accepted**: current and binding.
- **Deprecated**: retained but discouraged.
- **Superseded**: replaced by a linked ADR.
- **Rejected**: considered and not adopted.
