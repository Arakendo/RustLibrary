# Repository Root File Pack

These files are optional templates intended for the root of an adopted project.
Review and merge them individually; do not overwrite existing project documents
without reconciling their content.

| Fixture file | Target filename | Purpose |
| --- | --- | --- |
| `README.project.md` | `README.md` | Project entry point |
| `CONTRIBUTING.md` | `CONTRIBUTING.md` | Contribution workflow |
| `SECURITY.md` | `SECURITY.md` | Vulnerability reporting and supported versions |
| `SUPPORT.md` | `SUPPORT.md` | User-facing support routing |
| `CHANGELOG.md` | `CHANGELOG.md` | User-visible release history |

Replace all `{{...}}` placeholders and verify links after moving a file to the
project root.

This pack intentionally does not supply a `LICENSE` or a complete
`CODE_OF_CONDUCT.md`. Those documents carry legal or community commitments and
should be selected and approved deliberately rather than generated as neutral
boilerplate.
